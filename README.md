# OmicsXplore_platform_data

This repository contains exported data, analysis results, and supporting files generated using the OmicsXplore bioinformatics analysis platform.

The repository is intended to provide access to the analysis exports associated with the RNA-seq analysis and to support transparency and reproducibility of the reported results.

Repository Contents

The repository contains exported files generated during the RNA-seq analysis workflow, including processed data, annotation files, differential-expression results, and other analysis outputs where applicable.

The main analysis workflow comprises:
1. Quality control of raw sequencing reads and trimmed reads
2. Gene annotation
3. Differential-expression analysis using PyDESeq2
4. Downstream transcriptomic analyses and exported results, where applicable
5. Gene splicing and gene fusion detection results
